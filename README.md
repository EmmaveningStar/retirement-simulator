# 退休財務模擬器 v0.2

繁體中文、無外部依賴的靜態退休試算工具，以 iPhone Safari 的窄螢幕、16px 輸入與觸控操作為設計基準。

透過 HTTP 靜態伺服器開啟 index.html（使用 ES modules，請勿直接使用 file://）。無需建置。請勿將私人輸入寫入原始碼或範例。

## 功能與計算

- 本人／伴侶各自輸入股票、ETF、現金與每月淨投資／儲蓄；家庭模式相加，個人模式不含伴侶。
- 共同生活費、租金及房貸僅填一次。個人模式按負擔比例計入，家庭模式計入完整總額。
- 退休前投入為扣除生活與房貸後的淨額，避免再扣一次。退休後依通膨調整生活費，先提領現金，再提領投資。現金利率為零。
- 逐月名目複利，圖表另列今日購買力。房貸按月計息、月末支付，結束月償清餘額（可能有尾款）；本金不從流動資產重複扣除。未含房屋市值。
- 雙方共用退休時間，年齡以本人為準。首次可用資產為零即記錄耗盡，不將缺口累計為負債。
- localStorage 使用版本化專用 key，自動儲存所有輸入。清除只移除此工具資料並恢復中性示範值。損毀或不可用時顯示訊息並繼續試算，不讀取舊版可能含私人資料的 key。

## 驗證

`npm test` 執行計算模型與介面邏輯測試；介面以最小 DOM stub 測試，不代表真實 Safari 驗證。

合併前建議用實機 iPhone Safari 檢查：375px 與 390px 寬度、數字鍵盤、家庭模式、重新整理還原、清除資料、私人瀏覽／拒絕儲存、圖表與橫向表格捲動。目前環境沒有可用的指定瀏覽器工具，未執行實機測試。

本變更僅供 Pull Request 審查，不發布網站。所有預設值皆為中性示範。
